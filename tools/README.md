# Profile README tooling

Everything the profile README shows is generated by the scripts in this folder.
Every image lives in `assets/` as a self-contained file (fonts embedded, no
external requests), because GitHub serves README images through `<img>`: CSS
animation and SMIL play, but scripts and network requests don't.

| Script | Writes | Notes |
| --- | --- | --- |
| `build_hero.py` | `assets/hero.svg`, `hero-m.svg` and a `-still` copy of each | The ASCII jellyfish and the name. Takes a few seconds. |
| `jelly.py` | (used by `build_hero.py`) | The jellyfish simulation: bell, arms and tentacles sampled onto a character grid. |
| `build_panels.py` | Every other panel in `assets/`, plus the buttons | Reads `stats.json`. |
| `gitstats.py` | `stats.json` | Commit and line counts from local clones. |
| `svg_ascii.py` | (used by both builders) | Font subsetting (`font_face`). |

Requirements: Python 3.11+, `numpy`, `fonttools` and `brotli` (`pip install numpy fonttools brotli`).

## Rebuild

```bash
python tools/build_hero.py              # 48 frames, a 2 s loop
python tools/build_panels.py
```

`build_hero.py --mono` draws the jellyfish in greys instead of colour.
`--frames 24` gives a quicker test build.

## How the hero works

- **Frames.** `jelly.py` simulates one beat (2 s): the bell contracts and
  relaxes, the arms spiral, and a wave runs down each of the 16 tentacles a
  little behind the bell. Each of the 48 frames is a `<g>` of text rows, and a
  CSS step animation shows one at a time.
- **Colour.** Glyphs are painted by channel (bell, accent, rim, inner bell,
  arms, tentacles) with vertical gradients whose stops are animated by SMIL
  over six beats. On each beat a white-hot front runs down the body and leaves
  the next palette behind it. Colour is animated once for the file rather than
  baked into each frame, which keeps the file small (about 700 KB, 76 KB
  gzipped).
- **Scene.** Bloom (an SVG blur under the glyphs), a haze that breathes with
  the bell, faint drifting streaks, twinkling sparks, small jellyfish in the
  distance, and a spark burst on the last beat of the colour cycle.
- **Intro.** On first play the animal is drawn in from the top.
- **Reduced motion.** The README's `<picture>` serves the `-still` files to
  visitors who ask for reduced motion.

## Fonts

Geist and Geist Mono (Vercel, SIL Open Font License, `fonts/Geist-OFL.txt`).
Greek letters in code labels come from JetBrains Mono (`fonts/OFL.txt`),
because Geist Mono has no β or σ.
